# افزونه‌ی Obsidian (ورس‌آبس / Versobs)

[فهرست](index.md) · [English](../en/obsidian.md) · **فارسی**

**Versobs** افزونه‌ای برای Obsidian است که ابزارهای ورس‌لاین را به خود Obsidian می‌آورد: پیاده‌سازی متن، ترجمه، خلاصه، سؤال و فلش‌کارت، کدگذاری کیفی، نگارش پژوهش، اسلاید، خروجی Word/PDF، بایگانی تلگرام و گزارش پوشه‌ها. کار اصلی را ورس‌لاین در پس‌زمینه انجام می‌دهد؛ پس **ورس‌لاین باید نصب باشد** (راهنمای [نصب](installation.md)) و یک بار با `versline init` تنظیم شود. تنظیم سرویس، مدل، کلید API و پروکسی از صفحه‌ی تنظیمات خود افزونه هم ممکن است.

افزونه مخزن جداگانه‌ی خودش را دارد ([miroverse-solutions/versobs](https://github.com/miroverse-solutions/versobs)) و همراه ورس‌لاین ارائه نمی‌شود؛ ورس‌لاین فقط آخرین نسخه‌ی آن را برای شما دانلود و نصب می‌کند.

## نصب یا به‌روزرسانی افزونه

```sh
versline obsidian vaults                       # والت‌هایی که Obsidian روی این رایانه می‌شناسد
versline obsidian install                      # نصب در آخرین والتی که باز شده
versline obsidian install --vault ~/Notes      # یا در یک والت مشخص
versline obsidian status --vault ~/Notes       # نسخه‌ی نصب‌شده و آخرین نسخه
```

دستور `install` فایل‌های `manifest.json`، `main.js` و `styles.css` آخرین نسخه را در پوشه‌ی `<vault>/.obsidian/plugins/versobs/` قرار می‌دهد. فقط همین فایل‌ها جایگزین می‌شوند، پس تنظیمات افزونه (`data.json`) سر جایش می‌ماند. اجرای دوباره‌ی دستور، افزونه را به‌روز می‌کند یا اعلام می‌کند که به‌روز است. گزینه‌ها: `--version TAG` برای نصب یک نسخه‌ی مشخص، `--force` برای نصب دوباره، و `--proxy URL` برای پروکسی (پیش‌فرض: `VERSLINE_LLM_PROXY`). اگر GitHub محدودیت درخواست اعلام کرد، متغیر `GITHUB_TOKEN` را تنظیم کنید.

بعد از **اولین** نصب، Obsidian را باز کنید و از **Settings ← Community plugins** (اگر خواست، Restricted mode را خاموش کنید) افزونه‌ی **Versobs** را فعال کنید. بعد از به‌روزرسانی، Obsidian را دوباره بارگذاری کنید یا افزونه را یک بار خاموش و روشن کنید.

افزونه از داخل Obsidian هم خودش را به‌روز می‌کند: دکمه‌ی **Settings ← Versobs ← به‌روزرسانی افزونه** همین نصب‌کننده را برای والت فعلی اجرا می‌کند.

## ارتباط افزونه با ورس‌لاین

افزونه هر کار را با `versline bridge run <tool>` اجرا می‌کند؛ این یک رابط JSON است که در [کتابخانه: پروتکل bridge](library.md#پروتکل-bridge) توضیح داده شده. هر کار در یک پروسس جدا اجرا می‌شود، پس چند کار می‌توانند هم‌زمان پیش بروند. هر کاری را می‌شود لغو کرد و کار نیمه‌تمام در اجرای بعدی، مثل خط فرمان، از ادامه پیش می‌رود. فایل‌های موقت در پوشه‌ی کش ورس‌لاین نگه داشته می‌شوند (`~/.cache/versline/bridge`، یا در ویندوز `%LOCALAPPDATA%\versline\bridge`) و هرگز داخل والت شما قرار نمی‌گیرند.
