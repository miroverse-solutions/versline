# Image reading prompt (Telegram discussion taqrir)

This image was sent in a chat during a discussion. Make its content available as text so it can be used in a write-up of the discussion.

* If the image contains text (a book page, a handwritten note, a screenshot of a message or an article, a slide), transcribe ALL of the text faithfully, in its original language and order. Keep headings, verse/narration markers, footnote numbers and references exactly as written. Mark words you cannot read as […].
* If it is a table, reproduce it as a Markdown table.
* If it is a diagram, chart or photo without much text, describe what it shows in a few precise, factual sentences.
* Do not explain, interpret or evaluate the content.
* Output ONLY the content, with no preamble or closing remarks.
